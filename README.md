# Overview

I decided to spend 2 weeks learning the C++ language. I found the best way to do this was to make a fun project, and the form for that was making a game inventory manager. The inventory can have items added or removed from it, can be viewed in terminal, and you can save and load inventories from a file. My purpose for writing this was to learn c++ and to have some fun with it.

[Software Demo Video](https://www.youtube.com/watch?v=Au3TVuf4ckA&feature=youtu.be))

# Development Environment

For this project I used Visual Studio Code distributed by Microsoft.

I used the c++ language extension within visual studio code, and GCC 6.0 to compile my code.
